# 测试

```sh
# 仓库根目录起一个静态服务
python3 -m http.server 8099 &
cd test && npm ci && npm test
```

- `sched.js`   排程：多个时刻 × 全部卡片组合，每站必须落在自己的营业时段内，越界 0
- `smoke.js`   主流程：排今天 → 分享链接 → 客人拆信 → 愿意 → 「下次换你排」名字对调；
  英文收件人全流程；英文发件人首页 → 条件区 → 设置 → 一键 → 分享面板逐屏扫中文（卡池文案除外）；
  语言开关切回中文；中文首屏逐字不变（副标题是第 7 条那句「一句话说清是什么、给谁用」，一行放得下；
  第一屏只有「一键定今天」一个主按钮，定位排在「调一调」之后）；匿名计数五个点各记一次、只带动作名 + 短链 id
  （`POST /plans`、`POST /ev`、`GET /opened` 都被拦下来假装后台——**新加会打后台的页面时照 `evTrap` / `openedTrap` 拦，别让测试打到线上**）；
  她拆开了：短链到手就去问一次、回忆本记住 id；她（**另一个浏览器上下文** = 另一台手机）拆开后他切回前台问到 14:32，
  计划卡下面 / 分享面板 / 回忆本三处出现「瑶瑶拆开了 · 14:32」，下次打开直接从本机读不再问；他自己点开自己发的短链（同一上下文）不记 open；
  英文那条不是今天的带日期（`Yao opened it · Sep 27, 09:05`）；
  海报两种比例：计划图 750 宽、Story 1080×1920，二维码用 `jsqr` 解回站点地址，Story 上的字英文版无中文，
  足迹地图的瓦片被 `serveTile` 接住（深色 PNG，画上去那一块一定是暗的；要先 `setBypassServiceWorker`，不然 SW 把瓦片接走了拦不到）
- `shop.js`    商家入口：不要定位权限、起点 + 两站、出示按天去重、时钟在跳、首次/回头
- `layout.js`  文档宽不超过视口（iOS 缩放的根源），中文、英文各量一遍
- `daylight.js` 日照门槛：11 月天黑后不排需要天光的卡，6 月同一时刻照排

环境变量：`CHROME_PATH`（Chrome 路径）、`BASE_URL`（默认 `http://localhost:8099`）。
后端测试在 `server/`：`node test.mjs`。
