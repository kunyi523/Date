# TikTok · 三条 30 秒脚本

创始人故事：在加拿大，给女朋友做了这个。三条各站一个角度：他为什么做、她点开是什么样、两种语言一份计划。
同一条素材剪一遍就能同时发 TikTok / Reels / Shorts。旁白中英各一版，各自写的，不是互译；
中文版发小红书 / 抖音海外，英文版发 TikTok。口播节奏：英文 ≤ 75 词，中文 ≤ 105 字，都能在 27 秒内说完，留 3 秒给结尾。

## 拍之前

- 竖屏 1080×1920。网站在手机上直接录屏，别用模拟器；关掉通知。
- 主题用「夜色」——TikTok 的界面是黑的，深色卡片和金字在信息流里更跳；「晨光」只在第三条对比两台手机时用一次。
- 名字用你们自己的，或者「Kun & 【她】」。她的全名不出现。
- 音乐从 TikTok 商用曲库选，别用带版权的。
- 第一条里那段「今天干嘛 / 你定」的对话是写法，不是转述；不像你们就换成你们的那句。
- 演示用的短链现场生成一条（一键 → 分享 → 生成）。视频里出现的链接会过期，简介里放站点地址。

## 1 · 「你定」 · "You pick"

他为什么做。露脸 + 录屏。

### 镜头表

| 时间 | 画面 | 屏幕字 |
|---|---|---|
| 0–3 | 露脸，对镜头，一句话 | I built a website to end one conversation. |
| 3–7 | 黑底打字动画：两句对话 | "What do you want to do today?" → "I don't know, you pick." |
| 7–13 | 录屏：首屏 → 点「一键定今天」→ 花瓣 → 时间轴出来 | One tap. |
| 13–19 | 录屏：分享 → 生成 → 链接；切到聊天里的封蜡卡 | It becomes a link. |
| 19–26 | 她的手机：封蜡跳动 → 拆开 → 那句话 → 往下是安排 → 「I'm in ♥」 | The note comes first. |
| 26–30 | 露脸半秒，切站点地址 | Free · no app · link in bio |

### 旁白

**中文**（103 字）

```
我在加拿大，给女朋友做了个网页。
起因是每天那一轮：今天干嘛？随便，你定。
我点一下，它按现在几点、预算、天气、想跑多远，把今天排好，地点是附近真实的店。
然后封进一个链接。她点开是一枚封蜡，拆开先看到我写的那句话，再看到安排。
免费，不是 App。链接在简介。
```

**English**（74 词）

```

It started with one conversation: what do you want to do today — I don't know, you pick.
Now I tap once. It takes the time, our budget, the weather, how far we'll go, and plans today with real places nearby.

Free, no app. Link in bio.
```

## 2 · 「POV：他发了个链接」 · "POV: he sent you a link"

她点开是什么样。纯录屏，不露脸，节奏慢一点，让封蜡跳两下。旁白可有可无——字够了；要配就配下面这段。

### 镜头表

| 时间 | 画面 | 屏幕字 |
|---|---|---|
| 0–2 | 聊天界面，一张封蜡卡「Kun planned your day」 | POV: he sent you a link and it opened like this |
| 2–8 | 点卡片 → 全屏一枚封蜡在跳 → 手指点上去 → 花瓣落下 | （无字） |
| 8–14 | 那句话，她的语言；往下滑，Ⅰ Ⅱ Ⅲ 三站带时间 | The note comes before the plan. |
| 14–21 | 点「I'm in ♥」→ 弹出一句回话 → 点复制 → 切到聊天里粘贴发送 | You don't even have to think of a reply. |
| 21–27 | 按钮变成「Your turn next time →」→ 点 → 首屏，名字已对调 | Now it's your turn. Names already swapped. |
| 27–30 | 站点地址 | Free · no app · link in bio |

### 旁白（可选）

**中文**（80 字）

```
他发来一个链接，点开是一枚封蜡。
拆开，先是他写的一句话，再是今天的安排，几点到几点，去哪。
点「我答应你」，它给我一句回话，复制发回去，今天就说定了。
然后按钮变成「下次换你排」。名字已经对调好了。
```

**English**（62 词）

```
He sent a link. It opens to a wax seal.
Under the seal, his note first. Then today's plan — where, and when.
I tap "I'm in," and it hands me a reply line. Copy, send it back, and today is a date.
Then the button turns into "Your turn next time." The names are already swapped.
Free, no app. Link in bio.
```

## 3 · 「一份计划，两种语言」 · "Same plan, her language"

混语情侣 + 一天结束时那张图。两台手机并排，最后落在 Story 海报上。
**第一句是关于你们俩的事实。** 你们母语一样就用下面的「备选第一句」，第三人称拍，其他镜头不用动。

### 镜头表

| 时间 | 画面 | 屏幕字 |
|---|---|---|
| 0–3 | 两台手机并排：左边中文计划，右边同一份的英文 | We don't share a first language. |
| 3–10 | 镜头推近：同样的三站、同样的时间，两种文字 | We share a plan. |
| 10–17 | 录屏：打卡一站 → 地图上多一枚钉子 → 加一张照片 → 钉子变成照片 | Every place we actually go gets a pin. |
| 17–25 | 录屏：海报 → 切「Story · 9:16」→ 在一起 N 天最大，地图，二维码 | TOGETHER · [N] DAYS |
| 25–30 | 那张 Story 图全屏 1 秒 → 站点地址 | Free · no app · link in bio |

### 旁白

**中文**（95 字）

```
我们俩母语不一样。我用中文排，她用英文看，同样的三站，同样的时间。
真去过的地方会在地图上留一枚钉子，照片就钉在上面。
一天结束，它出一张图：在一起第几天，去过哪，一个二维码——扫一下，也能给你的人排一天。
免费，不是 App。链接在简介。
```

**English**（72 词）

```
We don't share a first language. I write the plan in Chinese; she reads it in English. Same stops, same times.
Every place we actually go leaves a pin on the map. Photos sit on the pins.
At the end of the day it makes this: how many days it's been, where we've been, and a code — scan it, and plan a day for yours, too.
Free, no app. Link in bio.
```

**备选第一句**（母语一样时替掉第一句和 0–3 秒的屏幕字）

```
有的情侣母语不一样。这个网页，他用中文排，她用英文看，同样的三站，同样的时间。
```

```
Some couples don't share a first language. Here, he plans in Chinese and she reads it in English. Same stops, same times.
```

屏幕字改成 `Not every couple shares a first language.`
